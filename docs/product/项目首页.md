# Mayari


基于 Cocos Creator 3.8.5 的 Web 游戏客户端，包含登录、加载、游戏主界面和弹窗。

## 协作约定

- 开发流程入口是 ai-dev-workflow 的 `workflow-core:workflow` 技能。项目配置见根目录 `ai-workflow.yaml`，项目术语见[术语表](术语表.md)。
- 同一事实只维护一处：业务规则归需求说明，产品状态归模块卡，设计节点归设计索引，技术任务归规格 tasks。
