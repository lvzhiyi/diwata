# 加载页与首页换肤

来源：[Figma / 11](https://www.figma.com/design/veKhCFadXm5yGRmi19d00S/11?node-id=25-130)。实际实现参考 Loading 1（25:18）、Loading 2（25:104）、主页面（25:130）；用户分享的 2:340 是旧弹窗底板。

## 素材与尺寸

- 桌面“加载切图”“游戏主页切图”导入独立目录 `assets/resources/skins/tropical-home`，共 65 张 PNG 和两套位图字体；`asset-map.json` 记录来源、尺寸、SHA-256 与 UUID。
- 两张独立引导插图由 Figma MCP 设计上下文提供并下载，整屏效果图未作为实现贴图。
- 设计尺寸 920×1629，按 750/920 等比映射到项目 750 宽。盘面内区 710×536、外框 796×638；保持六列 3/4/5/5/4/3 和 107 行距，符号图片为 144×130。
- 清晰符号来自带 hash 后缀的导出图，放在 `symbols/normal`；模糊符号来自数字文件名导出图，放在 `symbols`。均保留服务端数字 ID。
- 盘面与 OverLayer 共用缩放；转盘圆弧半径调整为 322.5，15 个倍率数据保持原值。

## 交互与动画

加载百分比、引导轮播、PLAY、不再显示、音量和按钮业务保留。新皮肤跳过旧主题全屏开场，复用原 BGM 初始化与关闭交接。

桌面素材没有新 Spine 动画。角色和按钮主体使用提供的静态图；symbol 落地、中奖、scatter、wild 转换使用保留新图案的节点缩放动画，避免播放中切回旧主题符号。特殊技能粒子/武器特效和未提供新图的附加入口仍沿用现有资源。


复核未发现剩余可确认的 P1/P2。项目原有音频/Spine 缓存权限和外部活动接口错误仍独立存在，本次未修改其资源或服务。

`editor-backup/main-before-home-verification.scene` 是重启前编辑器未保存场景的副本，原始 `assets/app-scene/main.scene` 未修改。备份位于 assets 外，不参与构建。
